IMPORTANT DECISIONS
-------------------
- Module C returns outside-|0> projected operator, NOT a partial trace of a unitary. Semantics explicitly labelled as "outside_zero_projection" with unitarity diagnostics.
- Module D embeds trial unitaries by explicit basis-index manipulation, never raw np.kron(U_trial, I) except when block qubits are proven leading axes. block_qubits are global labels; block_positions are local indices inside lightcone_qubits.
- per_bit_losses_from_V avoids the 4^s x 4^s full superoperator (impossible at s=10: 16 TB) by iterating env states and directly assembling 4x4 reduced superoperators.
- cirq.partial_trace returns subsystems in the order of keep_indices (no extra reordering needed).
- Ascending qubit order used everywhere; basis integers follow big-endian tensor order matching reduce(np.kron, ops) convention.
- All tests are plain Python scripts (no pytest); run from repository root with "python task2_code/<script>.py".
